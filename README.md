One word that describes my Wi-Fi: **moody**.

It works brilliantly when it feels like it, drops for no reason at all, and comes back the moment you stop watching it. No password, no reboot, no explanation — just moods. Everybody who has ever lived with home Wi-Fi knows exactly this feeling.

## Run

```sh
npm start
```

Writes the single word to `/output/entry.txt` (5 bytes, no trailing newline).
